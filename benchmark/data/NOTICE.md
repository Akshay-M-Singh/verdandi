# Benchmark data notice

The analysis set under this directory includes documents from third-party
datasets. All three are licensed under **Creative Commons Attribution 4.0
International (CC BY 4.0)**. The PDFs were normalized for this benchmark;
truth values were re-derived and verified. Synthetic documents were generated
by this project.

## CORD

- **Dataset:** CORD — A Consolidated Receipt Dataset for Post-OCR Parsing
- **Authors:** Seunghyun Park, Seung Shin, Bado Lee, Junyeop Lee, Jaeheung
  Surh, Minjoon Seo, Hwalsuk Lee
- **Venue:** NeurIPS 2019 Document Intelligence Workshop
- **Source:** <https://huggingface.co/datasets/naver-clova-ix/cord-v2>
- **License:** CC BY 4.0 — <https://creativecommons.org/licenses/by/4.0/>
- **Used for:** real Indonesian receipt photos (OCR/messy stratum)

## FATURA2

- **Dataset:** FATURA — A Multi-Layout Invoice Image Dataset for Document
  Analysis and Understanding
- **Authors:** Wided Limam, Mohamed Dhiaf, Mohamed Kessentini
- **Paper:** arXiv:2311.11856 (2023)
- **Source:** <https://huggingface.co/datasets/mathieu1256/FATURA2-invoices>
- **License:** CC BY 4.0 — <https://creativecommons.org/licenses/by/4.0/>
- **Used for:** generated multi-layout invoice images

## Invoices for Document AI

- **Dataset:** Invoices for Document AI (Kaggle, `holtskinner`)
- **Upstream source:** Kaggle "Text Extraction for OCR" (`manishthem`)
- **Source:** <https://www.kaggle.com/datasets/holtskinner/invoices-document-ai>
- **License:** CC BY 4.0 — <https://creativecommons.org/licenses/by/4.0/>
- **Used for:** scanned TIFF invoices with machine-generated Document AI
  labels (truth re-verified for this benchmark)

## Modifications

- Source images/documents were normalized to PDF page images; some pages were
  re-rendered or re-derived for a common benchmark input.
- Benchmark truth values were re-derived and verified for this project.
- The `syn_*` PDFs are synthetic documents generated by this project and are
  covered by the repository's Apache-2.0 license.

## Not included
